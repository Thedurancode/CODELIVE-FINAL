# Dispotree - The Universal Disposition Engine for Real Estate

## Overview

We're building the plug-in that connects every wholesaler CRM (existing platforms with deals) to all the major disposition channels — auctions, funds, syndication, and our own marketplace.

CRMs like InvestorLift, REI BlackBook, RealFlow, SimplyREI, DispoGenius, etc. can easily plug into our API. Their users just click "Send My Deal" and our technology handles the rest:

- Sends the deal to multiple marketplaces (Auction.com, Hubzu, Xome, etc.)
- Sends it to hedge funds and buy boxes
- Sends it to our internal marketplace
- Tracks everything in real time
- Sends real-time status updates and feedback back into their CRM

We basically become the communication and distribution layer for all wholesale deals.

And later, we can even offer our "Swipe" technology to major partners like Hubzu and Xome so they can use it for buyer feedback and engagement.

## In Short

We're not trying to replace CRMs — we're giving them the dispo power they never had. One API, one button, unlimited distribution.

## 📄 DISPO TREE — AI AGENT INVOLVEMENT OUTLINE (Developer-Friendly)

Clear definition of every AI agent and its responsibilities across the platform

### 1. AI CONTRACT ANALYSIS AGENT

**Purpose:** Ensure every uploaded wholesale contract is compliant, complete, and valid.

**Core Functions:**
- Parse contracts (PDF, SCAN, IMAGE → OCR → LLM extraction)
- Extract required fields:
  - Seller name(s)
  - Wholesaler entity
  - Assignability
  - Marketing clause
  - Access provision
  - Inspection period
  - Expiration date
- Validate signer identity:
  - Match wholesaler's uploaded LLC authorized signer
  - Match property owner via public-property-record API
- Apply state-specific rules:
  - Wholesale disclosures
  - Marketing limitations
  - Auction-services disclosure
- Detect missing clauses and generate:
  - Missing addenda
  - Compliance warnings (Green / Yellow / Red)

**Triggers & Outputs:**
- Flags deal compliance level
- Auto-populates missing deal fields
- Sends structured JSON to the backend for consistent ingestion

### 2. AI BUY-BOX MATCHING + FUND ROUTING AGENT

**Purpose:** Automate the entire institutional buyer (fund) workflow.

**What Makes This Unique:** Some funds do not have APIs — they require spreadsheets submitted by email. AI must handle:
- Matching deals to buy boxes
- Preparing spreadsheets
- Emailing the fund
- Following up
- Managing replies
- Requesting or retrieving offers
- Escalating once an offer exists

**Core Functions:**

**A. Buy Box Matching**
- System receives fund buy boxes in spreadsheet or CSV format
- AI interprets columns → builds rules
- Every new deal is evaluated:
  - If deal meets buy box → AI flags as a match
  - If deal partially meets → AI asks human for confirmation
- Generates a "Fund Match List" for each deal

**B. Spreadsheet Preparation**
- AI auto-fills fund-specific templates:
  - ARV
  - Purchase price
  - Estimated repairs
  - Rents (if needed)
  - Required disclosures
  - Attachments (photos, contract, etc.)

**C. Email-Based Integration Workflow**
For funds without API endpoints:
AI agent performs:
- Compose professional email
- Attach spreadsheet + property package
- Send to fund's acquisition email
- Log the outbound communication
- Wait for reply
- Follow up if no response within X hours/days:
  - "Checking in on the offer for 123 Main St…"
- Parse replies from fund:
  - Offer price
  - Questions
  - Declines
- Maintain conversation context
- Store the entire thread in CRM

**D. Offer Escalation**
When fund sends an offer:
- AI routes offer → Human disposition manager (trigger)
- Human approves counter or accepts
- AI can communicate back with fund if human approves

### 3. AI BUYER–WHOLESALER NEGOTIATION AGENT

**Purpose:** Prevent direct interaction & handle 80–90% of the negotiation communication.

**Core Functions:**
- Relay buyer questions to wholesaler
- Relay wholesaler answers back to buyer
- Relay offers + counteroffers
- Suggest counteroffer ranges using rules
- Summarize multiple offers into a ranked list
- Maintain guardrails:
  - Block phone numbers
  - Block emails
  - Block addresses
  - Block attempts to meet directly
  - Maintain compliance tone
- Encourage buyer engagement (nudges)
- Maintain updates - Example: "Still waiting for the wholesalers response, I'm trying them again now and will let you know asap. Just want you to know I'm on it. Thanks!"

**Escalation Triggers:**
AI delegates to human when messages involve:
- Requested access/showings
- Complex legal/contract questions
- Uncertainty about property condition
- Inspection requests requiring scheduling
- Angry/emotional/hostile messages
- Anything out of negotiation scope

### 4. AI OFFER RANKING & FEEDBACK AGENT

**Purpose:** Support the swipe technology and ranking system.

**Core Functions:**
- Score buyer interest based on:
  - Swipe behavior
  - "Likes"
  - Views/time on listing
  - Offer velocity
  - Buyer historical performance
- Generate a "Best Offer Prediction Score"
- Feed analytics into wholesaler dashboard
- Send nudges:
  - "This buyer has shown interest before, would you like to message them?"

### 5. AI DEAL DATA & UNDERWRITING AGENT

**Purpose:** Auto-fill missing deal info and assist wholesalers.

**Core Functions:**
- Pull AVM values (via Xome AVM API)
- Pull rent estimates
- Estimate light repair costs via rules or via future renovation module
- Auto-fill missing fields in the deal submission
- Summarize underwriting snapshot
- Provide "quick comps" when allowed by API

### 6. AI SYSTEM GUARDRAILS & COMPLIANCE ENFORCEMENT AGENT

**Purpose:** Ensure no one breaks rules or bypasses DispoTree.

**Core Guardrails:**
- Redact contact info
- Identify attempts to circumvent platform ("Let's meet directly" or "Call me at…")
- Reject direct assignment negotiations outside platform
- Detect broker-like behavior to avoid legal exposure
- Ensure neutrality between buyer and wholesaler
- Enforce messaging tone and compliance consistency

**Escalation Path:**
If the guardrail detects suspicious or legally risky messages → notify human immediately.

### 7. AI WORKFLOW ORCHESTRATOR

**Purpose:** The middleware that coordinates all agents.

**Responsibilities:**
- Detect which agent should handle each event:
  - Contract uploaded → Contract Agent
  - Deal created → Buy Box / Underwriting Agent
  - Buyer messages → Negotiation Agent
  - Fund follow-up → Email Agent
- Manage memory and conversation state
- Log every action
- Ensure data flows back into backend cleanly
