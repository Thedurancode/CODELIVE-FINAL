# Real Estate Due Diligence Checklist

## Overview

Due diligence is the investigation and verification process before finalizing a real estate transaction. This comprehensive checklist ensures you don't miss critical items.

## Property Information Verification

### Basic Details
- [ ] Verify property address (including unit number if applicable)
- [ ] Confirm lot size and dimensions
- [ ] Verify building square footage
- [ ] Confirm bedroom and bathroom count
- [ ] Check year built
- [ ] Verify property type and zoning

### Ownership Verification
- [ ] Obtain title report
- [ ] Verify current owner matches seller
- [ ] Check for co-owners or required signatures
- [ ] Verify seller has authority to sell
- [ ] Check for trusts, estates, or corporate ownership
- [ ] Confirm no pending litigation

## Title and Liens

### Title Search
- [ ] Order preliminary title report
- [ ] Review chain of title (last 30+ years)
- [ ] Check for breaks in chain of title
- [ ] Verify legal description matches

### Liens and Encumbrances
- [ ] Check for mortgage liens
- [ ] Verify property tax status (current or delinquent)
- [ ] Search for IRS tax liens
- [ ] Check for mechanic's liens
- [ ] Look for HOA liens
- [ ] Search for judgment liens
- [ ] Verify no code enforcement liens
- [ ] Check for utility liens

### Easements and Restrictions
- [ ] Review recorded easements
- [ ] Check deed restrictions
- [ ] Review CC&Rs if applicable
- [ ] Verify no encroachments
- [ ] Check for right-of-way issues

## Physical Property Inspection

### Exterior
- [ ] Roof condition and age
- [ ] Gutters and downspouts
- [ ] Siding/exterior walls
- [ ] Foundation (cracks, settling)
- [ ] Driveway and walkways
- [ ] Fencing and gates
- [ ] Landscaping and grading
- [ ] Exterior drainage

### Interior - Structure
- [ ] Foundation from inside (basement/crawlspace)
- [ ] Floor levelness and condition
- [ ] Wall condition (cracks, water stains)
- [ ] Ceiling condition
- [ ] Window condition and seals
- [ ] Door operation and condition
- [ ] Attic condition and insulation

### Systems
- [ ] HVAC system age and condition
- [ ] Water heater age and type
- [ ] Electrical panel (amps, condition)
- [ ] Plumbing (type, condition)
- [ ] Water pressure test
- [ ] Sewer/septic status
- [ ] Appliances included and working

### Safety
- [ ] Smoke detectors present
- [ ] Carbon monoxide detectors
- [ ] Handrails on stairs
- [ ] GFCI outlets in wet areas
- [ ] No exposed wiring
- [ ] No trip hazards

## Environmental and Hazards

- [ ] Check flood zone status (FEMA maps)
- [ ] Asbestos assessment (pre-1980 homes)
- [ ] Lead paint disclosure (pre-1978 homes)
- [ ] Radon testing if applicable
- [ ] Mold inspection
- [ ] Pest/termite inspection
- [ ] Underground storage tanks
- [ ] Check for environmental contamination

## Financial Due Diligence

### Valuation
- [ ] Pull comparable sales (3-6 months)
- [ ] Get Zestimate/AVM values
- [ ] Order appraisal if needed
- [ ] Calculate ARV for flips
- [ ] Verify price per square foot is reasonable

### Repair Estimates
- [ ] Get contractor walk-through
- [ ] Obtain written repair estimates
- [ ] Add 10-20% contingency
- [ ] Prioritize repairs by necessity
- [ ] Get multiple bids for major work

### Rental Analysis (if applicable)
- [ ] Research market rents
- [ ] Verify current lease terms
- [ ] Check tenant payment history
- [ ] Calculate cash flow projections
- [ ] Verify security deposits

### Costs
- [ ] Calculate closing costs
- [ ] Estimate holding costs
- [ ] Factor in financing costs
- [ ] Include insurance estimates
- [ ] Project utility costs

## Legal and Compliance

### Zoning and Permits
- [ ] Verify current zoning
- [ ] Check permitted use
- [ ] Pull permit history
- [ ] Verify no unpermitted work
- [ ] Check for code violations
- [ ] Verify occupancy certificate

### HOA/Condo (if applicable)
- [ ] Obtain HOA documents
- [ ] Review HOA financials
- [ ] Check for special assessments
- [ ] Verify monthly dues
- [ ] Review rules and restrictions
- [ ] Check for pending litigation

### Taxes and Assessments
- [ ] Verify current tax amount
- [ ] Check for special assessments
- [ ] Confirm tax payment status
- [ ] Understand reassessment triggers

## Market Analysis

- [ ] Research neighborhood trends
- [ ] Check days on market for area
- [ ] Analyze price trends (appreciation/depreciation)
- [ ] Research planned developments
- [ ] Check school ratings
- [ ] Review crime statistics
- [ ] Assess walkability/amenities

## Documentation Checklist

### Obtain from Seller
- [ ] Property deed
- [ ] Survey (if available)
- [ ] Property disclosures
- [ ] Utility bills (12 months)
- [ ] Repair/renovation receipts
- [ ] Warranties (roof, HVAC, etc.)
- [ ] HOA documents if applicable
- [ ] Current leases if rented

### Order/Obtain
- [ ] Title commitment
- [ ] Property inspection report
- [ ] Appraisal (if needed)
- [ ] Survey (if needed)
- [ ] Environmental reports
- [ ] Insurance quote

## Exit Strategy Verification

### For Wholesale
- [ ] Verify assignment is allowed
- [ ] Confirm buyer demand exists
- [ ] Calculate realistic assignment fee
- [ ] Have backup exit strategy

### For Flip
- [ ] Verify ARV with solid comps
- [ ] Confirm repair timeline is realistic
- [ ] Have contractor commitment
- [ ] Secure financing or funds

### For Rental
- [ ] Verify rental demand
- [ ] Confirm cash flow positive
- [ ] Check landlord-tenant laws
- [ ] Have property management plan

## Timeline

Typical due diligence period: **10-14 days**

| Day | Tasks |
|-----|-------|
| 1-2 | Order title report, schedule inspections |
| 3-5 | Property inspection, contractor walk-through |
| 5-7 | Review inspection reports, get repair estimates |
| 7-10 | Verify comps, finalize numbers |
| 10-14 | Make final decision, remove contingencies |

## Deal Killers

Issues that typically warrant walking away:

1. **Foundation problems** (major structural issues)
2. **Title defects** that can't be cleared
3. **Environmental contamination**
4. **Zoning violations** that can't be resolved
5. **Significant undisclosed damage**
6. **Numbers don't work** after true costs known
7. **Seller won't negotiate** after issues found
