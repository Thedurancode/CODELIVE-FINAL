# Buy Box Criteria Guide

## What is a Buy Box?

A buy box is a set of criteria that defines the ideal investment property for a buyer. Hedge funds, institutional buyers, and individual investors use buy boxes to quickly evaluate whether a property meets their investment strategy.

## Common Buy Box Criteria

### Location Criteria

**Geographic**
- Target states (e.g., TX, FL, GA, NC)
- Target markets/MSAs
- Specific zip codes
- Urban vs. suburban preference
- Distance from amenities

**Neighborhood Quality**
- School district ratings (e.g., 6+ rating)
- Crime statistics threshold
- Walkability score
- Employment center proximity
- Population growth trends

### Property Characteristics

**Property Type**
- Single Family Residential (SFR) - Most common
- Townhomes
- Condos (with restrictions)
- 2-4 Unit Multi-family
- Small Multi-family (5-20 units)

**Size Requirements**
- Minimum bedrooms: Usually 3+
- Minimum bathrooms: Usually 2+
- Minimum square footage: 1,000-1,500 sq ft
- Maximum square footage: 3,500-4,000 sq ft
- Minimum lot size: Varies by market

**Age and Condition**
- Year built range (e.g., 1970-2020)
- Acceptable foundation types
- Required systems age (HVAC, roof, water heater)
- Renovation level acceptable

### Financial Criteria

**Purchase Price**
- Minimum price: $50,000-$100,000
- Maximum price: $300,000-$500,000
- Price per square foot limits
- Below market value percentage

**Returns Requirements**
- Minimum cap rate: 5-8%
- Minimum cash-on-cash: 8-12%
- Minimum ROI: 15-25%
- Maximum MAO percentage: 70-75%

**Rental Metrics (Buy & Hold)**
- Minimum monthly rent
- Rent-to-value ratio (1% rule)
- Minimum cash flow per door
- Maximum vacancy rate in area

## Sample Buy Box Profiles

### Institutional Buyer (Hedge Fund)

```
Property Type: SFR only
Price Range: $150,000 - $350,000
Bedrooms: 3-4
Bathrooms: 2+
Square Feet: 1,200 - 2,500
Year Built: 1980 - 2015
Markets: Dallas, Houston, Atlanta, Tampa
Condition: Light renovation only (<$15,000)
Min Cap Rate: 5.5%
No pools, no septic, no flood zones
HOA max: $150/month
```

### Fix & Flip Investor

```
Property Type: SFR, Townhomes
Price Range: $75,000 - $200,000
ARV Range: $150,000 - $350,000
Repair Budget: $20,000 - $75,000
Min Profit: $25,000
Markets: Local market (50-mile radius)
Condition: Any (gut rehabs OK)
Foundation: Slab or pier & beam
Min ROI: 20%
```

### BRRRR Investor

```
Property Type: SFR, Small Multi
Price Range: $50,000 - $150,000
ARV Range: $125,000 - $250,000
Repair Budget: $25,000 - $50,000
Bedrooms: 3+
Markets: Midwest (Ohio, Indiana, Michigan)
Min Cash Flow: $300/month after refi
Target: 75% LTV refinance
Condition: Heavy renovation OK
```

### Turnkey Rental Buyer

```
Property Type: SFR
Price Range: $100,000 - $200,000
Bedrooms: 3+
Bathrooms: 2+
Year Built: 1990+
Markets: Birmingham, Memphis, Kansas City
Condition: Move-in ready or minimal work
Currently rented: Preferred
Min Cap Rate: 7%
Min Cash Flow: $200/month
Property management available
```

## Scoring Properties Against Buy Boxes

### Scoring Methodology

Properties are scored 0-100 based on how well they match buy box criteria:

| Match Level | Score Range | Description |
|-------------|-------------|-------------|
| Perfect Match | 90-100 | Meets all criteria, no concerns |
| Strong Match | 75-89 | Meets most criteria, minor deviations |
| Moderate Match | 60-74 | Meets core criteria, some concerns |
| Weak Match | 40-59 | Missing several key criteria |
| No Match | 0-39 | Does not meet fundamental requirements |

### Weighted Criteria Example

| Criteria | Weight | Impact |
|----------|--------|--------|
| Price in range | 20% | Deal breaker if exceeded |
| Location match | 15% | High importance |
| Property type | 15% | Must match |
| Bedroom count | 10% | Important |
| Year built | 10% | Moderate importance |
| Square footage | 10% | Moderate importance |
| Returns metrics | 15% | High importance |
| Condition | 5% | Can often be addressed |

## Creating Effective Buy Boxes

### Best Practices

1. **Be Specific**: Vague criteria lead to wasted time
2. **Prioritize**: Know which criteria are deal-breakers
3. **Stay Realistic**: Criteria too tight = no deals
4. **Review Regularly**: Markets change, adjust accordingly
5. **Document Everything**: Clear criteria prevent disputes

### Common Mistakes

1. **Too Restrictive**: Missing good deals
2. **Too Broad**: Wasting time on poor fits
3. **Ignoring Trends**: Not updating for market changes
4. **Missing Key Metrics**: Overlooking important factors
5. **Inconsistent Application**: Subjective decisions

## Auto-Submit Thresholds

Many funds set thresholds for automatic submission:

| Score | Action |
|-------|--------|
| 85+ | Auto-submit to acquisition team |
| 70-84 | Manual review recommended |
| 50-69 | Secondary priority |
| <50 | Do not submit |

## Market-Specific Considerations

### High-Appreciation Markets
- Accept lower cap rates (4-5%)
- Focus on equity growth
- New construction OK
- Higher price points acceptable

### Cash Flow Markets
- Require higher cap rates (7-10%)
- Older properties OK
- Lower price points
- Focus on rent-to-value ratio

### Emerging Markets
- Higher risk tolerance
- Population growth focus
- Job growth indicators
- Appreciation potential weighting
